# Projeto Básico Node.js

Este repositório contém a estrutura inicial de um projeto Node.js, desenvolvido como parte de uma atividade prática.

## 🚀 Estrutura do Projeto

- `package.json`: Arquivo de configuração e dependências do Node.js.
- `index.js`: Arquivo principal contendo exemplos práticos de JavaScript/Node.js.
- `README.md`: Documentação explicativa do projeto.

## 📝 Conteúdo Demonstrado

No arquivo `index.js`, foram implementados os seguintes conceitos:

1. **Variáveis:**
   - Uso de `const`, `let` e `var` para armazenar diferentes tipos de dados (strings, números e booleanos).
2. **Funções:**
   - Declaração de função tradicional (`function`).
   - Declaração de Arrow Function (`const func = () => {}`).

## 🛠️ Como Executar

1. Certifique-se de ter o **Node.js** instalado.
2. No terminal, execute o comando:
   ```bash
   node index.js
